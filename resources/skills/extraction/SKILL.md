# WebForge Extraction Skill

## هدف
تبدیل یک سایت عمومی به پروژهٔ محلی قابل‌اجرا و قابل‌ویرایش، با گزارش صادقانه از چیزهایی که استخراج نشده‌اند.

## قواعد
1. فقط سایت خودت یا سایتی که اجازهٔ تحلیل داری. برای سایت ثالث، تحلیل عمومی سطحی.
2. `robots.txt` و ToS رعایت شود. مسیر Disallow خزش نمی‌شود.
3. از لاگین، پرداخت، CAPTCHA، Cloudflare یا DRM عبور نکن. اگر بلاک شدی، توقف و گزارش.
4. کوکی نشست، Authorization، توکن و دادهٔ شخصی ذخیره یا گزارش نشود.
5. فاصلهٔ درخواست‌ها محترمانه؛ حداکثر ۸ اتصال هم‌زمان و پیش‌فرض ۴.
6. هر فایل باید از URL واقعی آمده باشد. هیچ محتوایی از خودت نساز.
7. `mirror/` خام و دست‌نخورده؛ هر بازنویسی فقط در `clean/`.
8. تکرارپذیری: مانیفست با hash، لاگ، و امکان اجرای دوباره.
9. هیچ فایل دانلودشده‌ای اجرا نمی‌شود.
10. گزارش نهایی: صفحات، دارایی‌ها، حجم، موارد ردشده و دلیل آن‌ها.

## چک‌لیست
- [ ] URL عمومی و معتبر (بدون private/loopback)
- [ ] robots.txt خوانده شد
- [ ] صفحهٔ اول و لینک‌های داخلی تا عمق مجاز
- [ ] CSS، JS، تصاویر، فونت، ویدیو و srcset
- [ ] دارایی‌های داخل CSS (`url()` و `@import`)
- [ ] بازنویسی مسیرها به نسبی
- [ ] مانیفست + گزارش + README
- [ ] هشدارها برای منابع ناموفق
