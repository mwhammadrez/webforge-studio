WebForge Studio 1.2.1 — Windows x64
===================================

1) Portable (پیشنهادی):
   WebForge Studio-1.2.1-portable.exe را اجرا کن. بدون نصب.
   اگر SmartScreen هشدار داد: More info → Run anyway (فایل امضای دیجیتال ندارد).

2) نصب‌کننده:
   WebForge Studio-1.2.1-x64.exe را اجرا کن. مسیر نصب قابل انتخاب است و
   میان‌بر دسکتاپ/منو می‌سازد.

3) نسخهٔ پوشه‌ای:
   پوشهٔ release\win-unpacked را باز کن و
   WebForge Studio.exe را اجرا کن (بدون نصب، همان فایل‌های داخل نصب‌کننده).

تغییر مهم این نسخه در ویرایشگر بصری:
   در نوار بالای ویرایشگر دکمه‌ای هست به نام «اسکریپت‌های سایت: خاموش».
   تا وقتی خاموش است، پیش‌نمایش دقیقاً همان فایل HTML را نشان می‌دهد و هر کلیکی
   که می‌کنی در همان فایل ذخیره می‌شود. این مشکل سایت‌هایی مثل Framer را حل می‌کند
   که اسکریپت خودشان صفحه را دوباره می‌سازد و باعث می‌شد هر ذخیره با پیام
   «نتوانستم فایل منبع این بخش را تشخیص دهم» شکست بخورد.
   اگر خواستی رفتار واقعی و انیمیشن‌های سایت را ببینی، دکمه را بزن تا روشن شود
   («اسکریپت‌های سایت: روشن»); در آن حالت ذخیرهٔ متنی که در فایل نیست رد می‌شود
   و دلیلش را نشان می‌دهد.

داده‌ها:
   %APPDATA%\WebForge Studio
   پروژه‌ها به‌صورت پیش‌فرض در Documents\WebForge Projects

کلید DeepSeek:
   Settings → هوش مصنوعی → کلید را وارد کن. با DPAPI ویندوز رمز می‌شود.

این نسخه روی ویندوز ۱۰ x64 ساخته و اجرا شده؛ اگر روی ماشین تو خطایی دیدی،
لاگ را از Settings → عیب‌یابی کپی کن و گزارش بده.
