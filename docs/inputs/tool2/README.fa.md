# سازنده پنل ادمین برای هر سایت استاتیک

هر سایت استاتیکی را می‌گیرد و به آن یک **پنل مدیریت کامل** اضافه می‌کند: همه‌ی متن‌ها، عکس‌ها و ویدیوهای سایت قابل ویرایش می‌شوند، بدون دست‌زدن به کد اصلی.

> روی خروجی ابزار «اکسترکتر سایت کاملل» تست شده (سایت Goldify با ۲۶ صفحه، ۲۰۷ تصویر، ۲۲۲ متن، ۱۱ ویدیو) و روی یک سایت ساده‌ی دست‌ساز.

---

## چه چیزی اضافه می‌کند؟

| فایل | کار |
|---|---|
| `admin.html` | پنل مدیریت: پیش‌نمایش زنده + ویرایش |
| `site-editor.js` | موتور اجرا در صفحات: `content.json` را می‌خواند و تغییرات را اعمال می‌کند |
| `content.json` | تنها منبع تغییرات (خالی = سایت دست‌نخورده) |
| `pages.json` | فهرست همه‌ی صفحات برای منوی پنل |
| `panel-config.json` | تنظیمات اختیاری (تصویر هیرو، سکه/عنصر اضافی) |
| `serve.ps1` | سرور محلی + API ذخیره‌سازی (PowerShell، بدون نیاز به نصب چیزی) |
| `run-panel.bat` | اجرای سرور با دابل‌کلیک |

نکته‌ی مهم: **هیچ فایل HTML بازنویسی نمی‌شود**؛ فقط یک `<script>` در انتهای هر صفحه تزریق می‌شود. پس اگر خواستی برگردی، همه‌چیز قابل بازگشت است.

---

## نصب روی یک سایت (۳ قدم)

```bat
:: 1) سایت را (که قبلاً استخراج کرده‌ای) انتخاب کن
python "<این پوشه>\kit\init_panel.py" "C:\path\to\site"

:: 2) سرور
cd "C:\path\to\site" && run-panel.bat

:: 3) پنل
http://localhost:8080/admin.html
```

اگر `python` نداشتی، از هر AI ایجنتی بخواه اسکریپت `kit/init_panel.py` را برایت اجرا کند — بدون پایتون هم می‌شود فایل‌ها را دستی کپی کرد (همان چهار فایل + دو فایل json).

### گزینه‌ها

| سوییچ | کار |
|---|---|
| `--force` | فایل‌های پنل را از نو کپی می‌کند (برای آپدیت نسخه) |
| `--hero-match <بخش-از-آدرس>` | تعیین دستی تصویر هیرو برای کنترل «نسبت تصویر» |

---

## کار با پنل

1. **منوی بالا**: انتخاب صفحه — هر صفحه‌ای که در `pages.json` باشد.
2. **عنصر انتخابی**: در پیش‌نمایش روی هر چیزی کلیک کن؛ متن، عکس، لینک، استایل (اندازه/رنگ/پس‌زمینه/شعاع)، مخفی‌کردن.
3. **همه محتوا**: فهرست کامل تصاویر + متن‌ها + ویدیوها با جستجو؛ تعویض عکس/ویدیو با آپلود؛ مخفی/نمایش هر ردیف؛ `↗` برای پرش به همان عنصر.
4. **هیرو**: تعویض تصویر اصلی، تغییر نسبت تصویر، و کلیدهای اضافی که در `panel-config.json` تعریف شده‌اند.
5. **ذخیره روی دیسک**: نوشتن `content.json` — تغییرات برای همه و همیشه.

---

## تنظیمات اختیاری — `panel-config.json`

```json
{
  "hero": { "match": "RmOfsEDOJPXj5pqYmVXNeepQJXE" },
  "extras": [
    { "name": "سکه‌های طلایی", "match": ["x1SyvORP", "h9yDaMAO"] }
  ]
}
```

- `hero.match`: بخشی از آدرس تصویر اصلی صفحه. اگر نباشد، پنل خودش «بزرگ‌ترین تصویر بالای صفحه» را هیرو حساب می‌کند.
- `extras`: هر آیتم یک کلید روشن/خاموش در تب «هیرو» می‌سازد که همه‌ی تصاویر هم‌نام را مخفی/نمایش می‌دهد (برای عناصر تزئینی مثل سکه، بج، استیکر).

## API (برای اتوماسیون)

| مسیر | متد | کار |
|---|---|---|
| `/api/content` | GET | خواندن `content.json` |
| `/api/content` | POST | نوشتن کل JSON (سقف ۸MB) |
| `/api/upload?name=file.png` | POST | ذخیره‌ی فایل در `assets/uploads/` (عکس/ویدیو تا ۶۰MB) |

---

## چه چیزهایی را کنترل می‌کند و چه چیزهایی را نه

✅ همه‌ی `<img>`های دیده‌شدنی · همه‌ی متن‌های تک‌تکه · همه‌ی `<video>`ها · متن/عکس/لینک/استایل/مخفی‌کردن هر عنصر با کلیک · نسبت تصویر هیرو

❌ افزودن عنصر جدید به صفحه (فقط ویرایش موجودها) · متن‌هایی که داخلشان تگ دیگری هست (دکمه‌ی آیکون‌دار) — فقط با کلیک روی عنصر · پس‌زمینه‌های CSS (اگر سایت از `background-image` استفاده کند) · ذخیره بدون اجرای سرور (باید `run-panel.bat` بالا باشد)

---

## چرا کار می‌کند (مدل داده)

```json
{
  "version": 1,
  "pages": {
    "/": {
      "hero":  { "image": "assets/uploads/x.webp", "ratio": "2.4", "extras": { "سکه‌های طلایی": false } },
      "overrides": {
        "#hero > div:nth-of-type(2) > h1:nth-of-type(1)": {
          "text": "متن جدید",
          "anchor": { "tag": "h1", "label": "متن قبلی" }
        }
      }
    }
  }
}
```

- هر تغییر با مسیر CSS ذخیره می‌شود؛ اگر بعد از رفرش آن مسیر نبود (فریم‌ورک‌ها گاهی یک لایه اضافه/کم می‌کنند)، با حذف یک لایه از مسیر و بعد با «متن/نام فایل قبلی» پیدا می‌شود.
- تغییرات در چند بازه (۰ تا ۴.۵ ثانیه پس از لود) دوباره اعمال می‌شوند تا اگر سایت خودش DOM را بازسازی کرد، از دست نروند.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| پنل باز نمی‌شود | `run-panel.bat` را اجرا کن؛ اگر پورت اشغال بود خودش ۸۰۸۱ و ۸۰۸۲ را امتحان می‌کند |
| «ذخیره نشد» | سرور باید در حال اجرا باشد؛ پنل از طریق `file://` کار نمی‌کند |
| تغییر اعمال شد ولی ماندگار نبود | «ذخیره روی دیسک» را بزن |
| عنصر پیدا نشد | پیش‌نمایش را با «بارگذاری مجدد» رفرش کن، دوباره انتخاب کن |
| عکس آپلود نمی‌شود | فرمت مجاز: png/jpg/webp/svg/gif · ویدیو: webm/mp4 · سقف ۶۰MB |
